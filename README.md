# frex-skills

Agent skills by [Frexuz](https://github.com/Frexuz). Install with the [skills CLI](https://skills.sh/docs/cli).

## Install

```bash
bunx skills add Frexuz/frex-skills
```

Install one skill:

```bash
bunx skills add Frexuz/frex-skills --skill fast-refresh-edit-order
```

List skills in this repo without installing:

```bash
bunx skills add Frexuz/frex-skills --list
```
